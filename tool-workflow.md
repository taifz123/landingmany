# Website Workflow

Maintain the existing static GitHub Pages website in this repository. Read the existing code and design guidance before changing it. Use Git history for versioning rather than creating duplicate site files. Respect the existing `CNAME` and business contact information.

After changes, review all public pages at mobile and desktop widths. Check navigation, accessibility, images, links, contact actions, responsive behavior, metadata and console errors. Keep the site functional without introducing unnecessary dependencies or claiming unverified results.
